## 二、留白（清空区）

**规则：X = 树冠高度 ÷ 4。**

- 树冠高度（金冠最上缘至最下缘）实测 **237.2** 单位

任何文字、图形、边框、裁切线不得进入清空区。三种锁定文件均已**预置**该留白（导出的 PNG/SVG 自带 X 边距），排版时直接贴边即可，不要自行再裁。

## 六、16 px 微缩版（micro）

标准图标在 16 px 下金冠内部镂空塌陷、树干细至 1 px，实测「糊成一团」。故单独出 micro 版：

- **做法**（可复现）：对源位图做形态学闭运算（椭圆核 5×5）→ 填掉面积 < 700 px² 的孔洞 → 重新描摹 → 画布内标志占比由 76.6% 提到 **92%**
- **效果**：16 px 下冠体连成整块、树干粗约 2 px、地面完整，可辨认为树
- **适用**：**仅 ≤32 px**。48 px 及以上用标准版（micro 在 48 px 已显钝，冠形细节丢失）
- 文件：`svg/yellowfir-icon-micro-color.svg`、`png/yellowfir-icon-micro-color-16.png`、`-32.png`
- `favicon.ico` 的 16/32 两档用 micro，48 档用标准版

## 七、错误用法（一律禁止）

1. **改比例**——拉伸/压扁树形或字标；树冠与树干的相对宽度、字标两行的高度比不得调整（见 §八 实测值）。
2. **换色**——不得改用规范色值以外的颜色（深底蓝干版已列入 §四 与 §五，属规范内）；不得把彩色版直接放深底（绿干对 `#284F34` 仅 **1.31:1**、对 `#111` 仅 **1.55:1**，树干会消失），深底必须用 `-on-dark`、`-on-dark-blue` 或 `-reverse`。
3. **加描边/发光/投影**——不得给标志本体加描边、外发光、投影；界面 CSS 投影只能加在容器上，不得烧进交付文件。
4. **改字距/换字体**——字标已转曲，不得用其他字体重排；不得单独拉伸字标。
5. **拆分重组**——树与字标不得改变相对位置另组新锁定；不得只取树冠丢弃树干。
6. **低对比底**——中灰、花纹、照片上必须用 `-reverse` 或先加深色蒙版；禁止彩色版直接压照片（除非该处实测对比 ≥3:1）。
7. **重绘**——不得用描图工具重新描摹本标志（本体系已提供矢量，重描会改变树形边缘）。

## 十一、制作方法与可复现性

全部资产由 `tools/build.py` 一次生成（幂等，可随时重跑）：

```
python3 build.py      # 读 yellowfir Logo.svg → 出 10 SVG + 50 PNG + favicon.ico + apple-touch-icon（共 63 个文件）
```

三个技术事实必须记住（影响后续任何改版）：

1. **`.af` 里的树是位图，不是矢量**。文件内该对象为像素层（Affinity 图层面板可见 `Pixel` 层），导出 SVG 中是 `<use href="#_Image5">` 引用的 398 × 290 px PNG。该位图在画板上的放置尺寸由变换算出为 **384.4 × 299.9**（横向 0.97×、纵向 1.03×，即近原生尺寸，纵向另有约 7% 拉伸），墨迹实测 388 × 304（含抗锯齿边）。因此本体系的树是**由该位图描摹（potrace）而来的矢量**，不是原生矢量；可用的最高原始分辨率为 398 × 290。
   - 描摹保真度：与源位图逐像素比对，**IoU = 0.9999**，金色/绿色分区一致率 1.0000。
   - 适用边界：形状忠实，但**边缘曲率为二次拟合**；若日后拿到原生矢量（Affinity 中若有更高分辨率像素层或原始 AI/EPS），应以原生矢量替换本描摹。
2. **字标是活文字**，`.af` 用 Palatino-Roman 与 Montserrat-Medium。本体系已**全部转曲**（`<text>` 计数 = 0），不依赖查看端字体。
   - 与源渲染比对（同一画板、同比例）：横向行首 dx = 0、dy = +1；`YELLOWFIR` 宽 −2 / 高 −3；`GROUP LIMITED` 宽 −9 / 高 −3（单位＝画板单位，基准宽 645/537）。差异来自字体度量与 Affinity 渲染的舍入，视觉不可辨。
3. **颜色取自文件值**，不含截图吸色。字标 `fill` = `#003e29`，底板 rect = `#284f34` / `#f5f5f5`，位图主色 `#C99A2E` / `#003E29`。

保真度总表（本体系渲染 vs 源画板同一区域，阈值 α>100）：

| 锁定 | 墨迹 IoU | 平均亮度差 |
|---|---|---|
| 图标 | 0.9504 | 2.3 / 255 |
| 横向 | 0.8737 | 3.5 / 255 |
| 竖向 | 0.8612 | 1.9 / 255 |

（锁定项 IoU 偏低系细笔画文字在 1 px 级错位所致，非形状错误；见上方 dx/dy 实测。）
